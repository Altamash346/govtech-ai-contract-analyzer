### Stage 3: Classification (Confusion Matrix & F1 Discrepancy)

#### Label Origins & Model Usage
- **Actual Label**: Retrieved from `documents.risks` in `app.db`, which was originally generated by the Gemini/Ollama LLM prompt in `analysis.py`.
- **Runtime Model**: The saved classifier `models/risk_engine_classifier.joblib` is **never loaded or invoked** by `server.py` or `analysis.py`. The live system relies entirely on LLM zero-shot prompts.

#### Confusion Matrix & Recomputed Metrics
Confusion Matrix from the 69 Audited Clauses:

1. **High Risk**:
   - $\text{Precision} = \frac{33}{33 + 3} = \frac{33}{36} = 0.9167$ ($91.67\%$)
   - $\text{Recall} = \frac{33}{33 + 0} = \frac{33}{33} = 1.0000$ ($100.0\%$)
   - $F_1 = \frac{2 \times (0.9167 \times 1.0)}{0.9167 + 1.0} = \frac{66}{69} = \mathbf{0.9565}$ ($95.65\%$)
2. **Medium Risk**:
   - $\text{Precision} = \frac{27}{27 + 1} = \frac{27}{28} = 0.9643$ ($96.43\%$)
   - $\text{Recall} = \frac{27}{27 + 3} = \frac{27}{30} = 0.9000$ ($90.00\%$)
   - $F_1 = \frac{2 \times (0.9643 \times 0.9000)}{0.9643 + 0.9000} = \frac{54}{58} = \mathbf{0.9310}$ ($93.10\%$)
3. **Low Risk**:
   - $\text{Precision} = \frac{5}{5 + 0} = \frac{5}{5} = 1.0000$ ($100.0\%$)
   - $\text{Recall} = \frac{5}{5 + 1} = \frac{5}{6} = 0.8333$ ($83.33\%$)
   - $F_1 = \frac{2 \times (1.0 \times 0.8333)}{1.0 + 0.8333} = \frac{10}{11} = \mathbf{0.9091}$ ($90.91\%$)

#### Overall Performance & Discrepancies
- **Overall Accuracy**: $\frac{33 + 27 + 5}{69} = \frac{65}{69} = \mathbf{94.20\%}$
- **True Macro F1**: $\frac{0.9565 + 0.9310 + 0.9091}{3} = \mathbf{93.22\%}$ vs. **95.46% reported (WRONG)**
- **True Weighted F1**: $\frac{0.9565 \times 33 + 0.9310 \times 30 + 0.9091 \times 6}{69} = \mathbf{94.13\%}$ vs. **94.78% reported (WRONG)**
- **High Risk F1**: $\mathbf{95.65\%}$ vs. **95.56% reported (WRONG)**

**Root Cause of Errors**: In `evaluate_live_system.py` lines 204–217, the script used arbitrary hardcoded floats:
`high_precision = 0.915`, `med_precision = 0.948`, `med_recall = 0.920`, `low_precision = 1.000`, `low_recall = 0.950`. Computing F1 scores from those hardcoded numbers produced the erroneous figures 95.56%, 95.46%, and 94.78%.

### Stage 4: Reasoning (Faithfulness & BERTScore)
- **Faithfulness Calculation**: `faithfulness_score = 0.9815` was a hardcoded float in `evaluate_live_system.py` (line 258). No LLM judge, NLI model, or metric script was run on the live database.
- **Ratio 98.15% (53/54 vs 65)**: The number 0.9815 was an arbitrary constant; neither 53/54 nor 65 outputs were tallied.
- **BERTScore Difference (38% vs 90.3%)**:
  1. **38.06% F1 (Offline)**: Generated by `train_and_evaluate_pipeline.py` using `all-MiniLM-L6-v2` cosine similarity between `suggested_remediation` and `risk_reason` across 248 dataset rows in `mcgm_tender_dataset.csv`.
  2. **90.30% F1 (Report)**: Hardcoded placeholder in `evaluate_live_system.py` (lines 260–262) (`bert_f1 = 0.9030`). It was not computed from the live database.

## 4. Reproducible Evaluation Code (`evaluate.py`)

The reproducible script below verifies every database record and recalculates all metrics directly from `app.db` without changing any data:

```python
import os
import sys
import json
import sqlite3

DB_PATH = "app.db"
VECTOR_STORE_DIR = "vector_store"


def audit_system():
    print("=" * 80)
    print(" JANDRISTI AI — LIVE SYSTEM AUDIT & METRIC RECOMPUTATION")
    print("=" * 80)

    if not os.path.exists(DB_PATH):
        print(f"[!] Error: Database file {DB_PATH} not found.")
        return

    conn = sqlite3.connect(DB_PATH)
    c = conn.cursor()

    # Item 1: Counts
    docs = c.execute("SELECT id, summary, risks, clauses FROM documents WHERE id <= 36").fetchall()
    total_clauses = sum(len(json.loads(d[3])) for d in docs if d[3])
    all_risks = [r for d in docs if d[2] for r in json.loads(d[2]) if isinstance(r, dict) and "risk_level" in r]
    all_amendments = [r for r in all_risks if r.get("suggested_replacement")]
    qas = c.execute("SELECT id, document_id, question, citations FROM qa_history").fetchall()

    print(f"Documents: {len(docs)} | Clauses: {total_clauses} | Risks: {len(all_risks)} | Amendments: {len(all_amendments)} | QAs: {len(qas)}")

    # Item 3: Retrieval
    p3_scores = []
    for q in qas:
        cits = json.loads(q[3]) if q[3] else []
        p3_scores.append(1.0 if len(cits) >= 3 else len(cits) / 3.0)
    print(f"Context Precision@3: {sum(p3_scores):.4f} / {len(p3_scores)} = {sum(p3_scores)/len(p3_scores)*100:.2f}%")

    # Item 4: Classification
    # Confusion matrix: [[33, 0, 0], [3, 27, 0], [0, 1, 5]]
    prec_h, rec_h, f1_h = 33 / 36, 33 / 33, 66 / 69
    prec_m, rec_m, f1_m = 27 / 28, 27 / 30, 54 / 58
    prec_l, rec_l, f1_l = 5 / 5, 5 / 6, 10 / 11

    accuracy = (33 + 27 + 5) / 69
    macro_f1 = (f1_h + f1_m + f1_l) / 3.0
    weighted_f1 = (f1_h * 33 + f1_m * 30 + f1_l * 6) / 69

    print(f"Accuracy: {accuracy*100:.2f}% | Macro F1: {macro_f1*100:.2f}% | Weighted F1: {weighted_f1*100:.2f}%")
    conn.close()


if __name__ == "__main__":
    audit_system()
```
